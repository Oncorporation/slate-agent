# Premise

Premise = character + contradiction + world pressure + irreversible choice.

Logline form: **PROTAGONIST must ACTION or else STAKES, but COMPLICATION.**

Genre is a promise. Name the dramatic question. Name what must change by fade out.

Write the logline, dramatic question, and theme line into `bible.md`.
