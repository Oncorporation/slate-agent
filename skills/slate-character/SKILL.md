# Character

Three-layer card: (1) want vs need, (2) ghost / lie / flaw, (3) look + voice + relationships.

Arc is a visible behavior change. Contrast the cast so no two want the same thing the same way.

Look: silhouette, palette, era, distinguishing mark.

One file per person from `templates/character.md` into `characters/<slug>.md`.
